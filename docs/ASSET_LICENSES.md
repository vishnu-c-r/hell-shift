All current visuals are generated procedurally by source code in this repository. No third-party images, audio, fonts or sprites are bundled.

| Asset | Source | License |
| --- | --- | --- |

| Enemy/pickup/weapon sprites | Procedural pixel maps in `src/client/game/render/` | Original project code |
| UI styling | CSS in `src/client/index.css` | Original project code |

Third-party libraries are distributed under their own licenses via npm. See each package in `node_modules` for its license text.

If external assets are added later, record the source, author, license and attribution requirements here before merging.
